# NVIDIA Auto Ontology 패치

`llm_invoke.patch`는 NVIDIA Auto Ontology(https://github.com/NVIDIA/auto-ontology, Apache License 2.0)의 `auto_ontology/utils/llm_invoke.py`에 대한 변경분이다. 원본 파일은 NVIDIA 저작물이라 이 저장소에 넣지 않았다. Auto Ontology 저장소를 받은 뒤 그 루트에서 `git apply <이 폴더>/llm_invoke.patch`로 적용한다. 패치는 원본과 같은 Apache License 2.0을 따른다(이 저장소의 MIT 라이선스와 별개).
