# 용어 19개
- Code: A numeric or alphanumeric code representing sequential identifiers like order nu
- Code Group: Categorical grouping codes representing business status categories such as regio
- Code Name: A Korean language description column providing human-readable status names for o
- Customer Master: Core customer record containing identification, classification, and geographic i
- Equipment: Represents a physical equipment unit in the production environment.
- Insp: Business entity represented by table insp
- Insp Dfct: Business entity represented by table insp_dfct
- Item Master: Core product catalog data for finished goods and raw materials
- Lot: A production batch with its quantity and date.
- Lot Completion: Tracks the quantity of units used to complete a lot.
- Plant: Manufacturing facility information
- Production Line: (설명 없음)
- Rcv Lot: Business entity represented by table rcv_lot
- Sales Order: A unique sales order identifier used to track individual customer orders.
- Sales Order Detail: Line items within a sales order
- Shipment: Tracks shipment dispatch and item quantities.
- Vendor: Core vendor master data
- Work Order: Tracks production activities and associated tasks linked to customer orders.
- Workout Exercise: Tracks running activity metrics including duration and segment breakdowns.
