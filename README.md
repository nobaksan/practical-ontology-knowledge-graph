# 실전 온톨로지와 지식그래프 엔지니어링

『실전 온톨로지와 지식그래프 엔지니어링』(김동우 지음, 케이리아파트너스, 2026)의 예제 코드 저장소다.

폴더 구조는 본문과 같다. 3·4·5·11·12장 실습은 `실행_환경/실습/`(결과는 `실행_환경/실습/결과/`), Docker 구성은 `실행_환경/docker/`에 있다. 12장 Auto Ontology 실습의 NVIDIA API 키와 토큰은 환경 변수로만 넘긴다(`DEFAULT_MODELS_API_KEY`, `AUTO_ONTOLOGY_API_TOKEN`).

## 주의

- API 키·토큰·비밀번호는 저장소에 넣지 않았다. 본문 안내대로 환경 변수나 `.env`로 넘긴다. Docker 구성의 비밀번호는 로컬 실습용 예시 값이다.
- 모델 이름·요금·제품 화면은 책의 확인 일자 이후 바뀔 수 있다.
- 이 책과 저장소는 본문에 나오는 제품·서비스의 회사와 관련이 없는 비공식 자료다.
